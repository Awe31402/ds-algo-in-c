## 785 · Is Graph Bipartite?（Medium）
[題目](https://leetcode.com/problems/is-graph-bipartite/) · [程式](0785-is-graph-bipartite.c)

**題意**：無向圖能不能把頂點分成兩群，讓每條邊都跨在兩群之間？

**思路**：BFS 兩色著色。
- 起點塗 0，鄰居塗 1，鄰居的鄰居塗 0……
- 遇到一條邊的兩端**同色** → 不是二分圖。

**等價條件**：二分圖 ⇔ **沒有奇數長度的環**。三角形一定不是二分圖；正方形是。

**複雜度**：O(V + E)。

**陷阱**：圖**可能不連通**，每個還沒塗色的頂點都要當起點再做一次。

## 1947 · Maximum Compatibility Score Sum（Medium）
[題目](https://leetcode.com/problems/maximum-compatibility-score-sum/) · [程式](1947-maximum-compatibility-score-sum.c)

**題意**：m 個學生、m 個導師一對一配對。每一對的分數是問卷答案相同的題數，總分最大是多少？

**思路**：這是**指派問題**，也就是二分圖的**最大權重完美匹配**。
- m ≤ 8 時，暴力枚舉 8! = 40320 種排列也會過（本機測試就用它來對照答案）。
- 標準解是**匈牙利演算法**（CLRS 25.3），O(m³)。本檔實作的是最小成本版本，所以把分數取負號。

**匈牙利演算法的直覺**：
- 每個學生 i 有位能 u[i]、每個導師 j 有位能 v[j]，隨時維持 `u[i] + v[j] ≤ cost[i][j]`。
- 只沿著「**緊的邊**」（u[i] + v[j] == cost[i][j]）找增廣路徑。
- 找不到時，調整位能（減掉 delta），讓至少一條新的邊變緊，再繼續找。
- 所有人都配到時，總成本 = 位能總和 = 最小值。

**複雜度**：O(m³)。

**其他做法**：bitmask DP，`dp[mask]` = 前 popcount(mask) 個學生配到 mask 這些導師的最大分數，O(2ᵐ · m)。

## 1349 · Maximum Students Taking Exam（Hard）
[題目](https://leetcode.com/problems/maximum-students-taking-exam/) · [程式](1349-maximum-students-taking-exam.c)

**題意**：m × n 的教室，`'.'` 可以坐、`'#'` 不能坐。學生可以看到**左、右、左前、右前**的考卷。最多能坐幾個人，而且沒有人能作弊？

**思路**：
1. 把「會互相看到」的兩個座位連一條邊。要找的是**最大獨立集**：選最多個點，彼此之間沒有邊。
2. 一般圖的最大獨立集是 NP-hard，但**這張圖是二分圖**：會衝突的兩個座位，行號一定差 1，所以一個在奇數行、一個在偶數行。
3. 二分圖上，**König 定理**：最大獨立集 = 點數 − 最大匹配。
4. 最大匹配用增廣路徑（Kuhn 演算法），從偶數行的座位出發。

```
座位 A(第 0 行) 和 B(第 1 行) 衝突 → 邊 A−B
最大匹配 k 對 → 每一對至少要放棄一個人 → 最多坐 總數 − k 人
```

**複雜度**：座位最多 64 個，O(V E) 很快。

**其他做法**：逐列 bitmask DP。每一列用一個 bitmask 表示誰坐，檢查同一列不相鄰、跟上一列的斜對角不衝突，O(m · 4ⁿ)。這是這題最常見的解法；本檔示範的是另一個角度：用匹配解。

**陷阱**：衝突是雙向的（我看得到你 ⇔ 你看得到我），所以建圖時要包含「左後、右後」兩個方向，邊才會完整。
