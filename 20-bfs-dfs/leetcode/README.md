## 733 · Flood Fill（Easy）
[題目](https://leetcode.com/problems/flood-fill/) · [程式](0733-flood-fill.c)

**題意**：小畫家的「油漆桶」：從 (sr, sc) 開始，把同色而且上下左右相連的格子都塗成新顏色。

**思路**：遞迴 DFS。塗上新顏色之後，這格就不會再等於舊顏色，所以塗色本身就是「已拜訪」的標記。

**複雜度**：O(mn)。

**陷阱**：**新顏色跟舊顏色一樣時，要直接回傳。** 否則塗完還是舊顏色，會一直重複拜訪，變成無限遞迴。

## 200 · Number of Islands（Medium）
[題目](https://leetcode.com/problems/number-of-islands/) · [程式](0200-number-of-islands.c)

**題意**：`'1'` 是陸地、`'0'` 是水。上下左右相連的陸地算同一座島，總共有幾座島？

**思路**：這就是「數連通元件」。
- 掃過每一格，遇到還沒拜訪過的 `'1'`：島數 +1。
- 從這格 BFS，把整座島都標記成 `'0'`。

**複雜度**：O(mn)，每格最多進 queue 一次。

**陷阱**：
- **放進 queue 時就標記**，不要等到拿出來才標記。
- 遞迴 DFS 在 300 × 300 全是陸地時，深度可以到 9 萬層，可能爆堆疊。本檔用 BFS 加上自己的 queue。
- 斜對角不算相連。
- 另一個做法：Union-Find（第 22 主題）。

## 841 · Keys and Rooms（Medium）
[題目](https://leetcode.com/problems/keys-and-rooms/) · [程式](0841-keys-and-rooms.c)

**題意**：房間 0 是開的，每個房間裡有其他房間的鑰匙。能不能進得了所有房間？

**思路**：房間是頂點，「房間 u 有 v 的鑰匙」就是一條邊 u → v。從 0 出發走訪，看能走到幾個頂點。

**複雜度**：O(V + E)。

**陷阱**：這是**有向圖**。u 有 v 的鑰匙，不代表 v 有 u 的鑰匙。

## 994 · Rotting Oranges（Medium）
[題目](https://leetcode.com/problems/rotting-oranges/) · [程式](0994-rotting-oranges.c)

**題意**：每分鐘，爛橘子會讓上下左右的新鮮橘子也爛掉。全部爛掉要幾分鐘？做不到就回傳 -1。

**思路：多源 BFS**
- 一開始把**所有**爛橘子一起放進 queue，當作第 0 分鐘。
- 分層 BFS：每一層就是一分鐘。
- 最後還有新鮮橘子 → -1。

```
2 1 1      2 2 1      2 2 2      2 2 2      2 2 2
1 1 0  →   2 1 0  →   2 2 0  →   2 2 0  →   2 2 0
0 1 1      0 1 1      0 1 1      0 2 1      0 2 2
 0 分鐘     1 分鐘     2 分鐘     3 分鐘     4 分鐘
```

**複雜度**：O(mn)。

**陷阱**：
- **一開始就沒有新鮮橘子**：答案是 0，不是 -1。
- 迴圈條件加上 `fresh > 0`，最後一層擴散完就停，不會多算一分鐘。
- 如果每個爛橘子各自做一次 BFS，會變成 O((mn)²)。多源 BFS 只要一次。

## 1091 · Shortest Path in Binary Matrix（Medium）
[題目](https://leetcode.com/problems/shortest-path-in-binary-matrix/) · [程式](1091-shortest-path-in-binary-matrix.c)

**題意**：n × n 的格子，從左上走到右下，只能走 0，可以往 8 個方向走。最短的路徑經過幾格？

**思路**：每走一步的代價都是 1，所以 BFS 第一次到達終點時的距離就是最短距離。

**複雜度**：O(n²)。

**陷阱**：
- **起點或終點本身是 1** → 直接回傳 -1。
- 題目算的是「經過幾格」，所以起點的距離是 **1**，不是 0。
- 8 個方向用兩層迴圈 `dr, dc ∈ {-1, 0, 1}` 最好寫，(0, 0) 那一格已經拜訪過，會自動被跳過。
- 用 DFS 找最短路徑是錯的：DFS 第一次走到終點的路徑不一定最短。
