# 18 · Red-Black Tree 紅黑樹

## 一句話
**紅黑樹**是一種「大致平衡」的 BST：每個節點塗上紅色或黑色，靠五條顏色規則保證**最長的路徑不會超過最短的兩倍**。所以高度 ≤ 2 log₂(n+1)，搜尋、插入、刪除都是 O(log n)。

## 五條性質（CLRS 13.1）
1. 每個節點是紅或黑。
2. **根是黑的。**
3. 每個葉子（NIL）是黑的。
4. **紅節點的小孩都是黑的**（不能連續兩個紅）。
5. **從任一節點往下到每個 NIL，經過的黑節點數都一樣**，這個數字叫 black-height。

為什麼高度 ≤ 2 log(n+1)：性質 5 讓「只算黑節點」的樹是完美平衡的；性質 4 讓紅節點最多和黑節點一樣多。所以最長路徑 ≤ 2 × 最短路徑。

### 哨兵 NIL (sentinel)
所有的 NULL 都指向同一個黑色的 `nil` 節點。這樣 `x->left->color` 永遠可以讀，不用先判斷是不是 NULL。刪除的修正也要用到 `nil->parent`。

## 插入（CLRS 13.3）
新節點塗**紅色**，因為紅色不會破壞性質 5。可能出問題的只有：父節點也是紅的（違反性質 4），或新節點就是根（違反性質 2）。

z 是新節點，p 是父，g 是祖父，u 是叔叔 (uncle)。以 p 是 g 的左小孩為例：
```
情況 1：叔叔 u 是紅的 → 變色，問題往上丟兩層
        g(B)                 g(R)   ← 現在 g 可能跟它的父節點衝突，繼續往上
       /    \               /    \
     p(R)   u(R)    →     p(B)   u(B)
     /                    /
   z(R)                 z(R)

情況 2：叔叔黑，z 是「折線」(z 是右小孩) → 左旋 p，變成情況 3
情況 3：叔叔黑，z 是「直線」(z 是左小孩) → p 變黑、g 變紅、右旋 g，結束
        g(B)                  p(B)
       /    \                /    \
     p(R)   u(B)    →      z(R)   g(R)
     /                               \
   z(R)                              u(B)
```
插入最多旋轉 **2 次**。

## 刪除（CLRS 13.4）
先照 BST 的方式刪除（一樣是 TRANSPLANT 那三種情況）。如果**真正被移走的那個位置原本是黑的**，某些路徑就少了一個黑節點，性質 5 被破壞了。

想像取代它的節點 x 多背了一層「額外的黑」，修正的目標是把這層額外的黑消化掉。w 是 x 的兄弟：
| 情況 | 條件 | 做法 |
|---|---|---|
| 1 | 兄弟 w 是紅的 | w 變黑、父變紅、父左旋 → 轉成 w 是黑的情況 |
| 2 | w 黑，w 的兩個小孩都黑 | w 變紅，額外的黑往上推給父節點 |
| 3 | w 黑，w 的左小孩紅、右小孩黑 | w 右旋 → 轉成情況 4 |
| 4 | w 黑，w 的右小孩紅 | 變色 + 父左旋，額外的黑被消化，**結束** |

刪除最多旋轉 **3 次**。

| 操作 | 時間 | 旋轉次數 |
|---|---|---|
| 搜尋 / lower_bound | O(log n) | — |
| 插入 | O(log n) | ≤ 2 |
| 刪除 | O(log n) | ≤ 3 |
| 高度 | ≤ 2 log₂(n + 1) | |

## 面試陷阱／常考點
1. **五條性質要背得出來**，面試最常問的就是這個。
2. **新節點為什麼是紅的？** 塗黑的話，那條路徑的 black-height 馬上多 1，一定違反性質 5；塗紅最多只違反性質 4，比較好修。
3. **紅黑樹 vs AVL**：紅黑樹比較鬆（高度 ≤ 2 log n，AVL ≤ 1.44 log n），但插入、刪除的旋轉次數有常數上界，所以修改頻繁時比較快。見 17 主題的比較表。
4. **紅黑樹在哪裡**：C++ `std::map` / `std::set`、Java `TreeMap`、Linux 核心的 CFS 排程器和記憶體管理。
5. **紅黑樹 ↔ 2-3-4 樹**：一個黑節點加上它的紅小孩，可以看成 B-tree 的一個節點。這個對應關係可以幫忙理解所有的情況（第 31 主題 B-Tree）。
6. **面試不太會要你手寫紅黑樹**，但會問「有序集合」的用法：找前一個／下一個、範圍查詢、滑動視窗裡的有序資料（LeetCode 729、220）。
7. **C 沒有內建的有序集合**，要自己寫，或改用 heap、排序陣列加二分搜尋等替代方案。
